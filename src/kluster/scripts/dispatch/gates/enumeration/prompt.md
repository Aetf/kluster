You are shown a change under review: each file it writes, whole, with what
it writes marked. Ask one question of what the change writes: does a
passage name the members of a set one by one where a definition of the set
would cover them, so that the next member needs an edit there?

A set is any class the code, a test or a rule acts on or describes: the
components or programs of the installation, the objects in a namespace,
the families a census holds, the cases a function refuses, the spellings a
reader cannot read, the settings a component owns. Its members may be
named by literal, by name, or by the conditions that pick each one out.

The rule says where members may still be named. Find which of those
places, if any, the passage is. Where the passage or what surrounds it
states what the set is (a predicate the code tests, a docstring, a program
the members could be derived from) and the passage names the members
instead of deriving them, it is a finding; so is a passage that names
members with no definition at all, unless it is the census.

Report each such passage, with one sentence naming the set and the
definition that covers it.
